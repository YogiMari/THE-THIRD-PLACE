Liber I

Genesis原典

すべての文書は、一つの思想から生まれる（OP-001 §25）。その思想を記した不変の原典が DS-001 であり、それをプロジェクト運営の条文として再定義したものが OP-001 §3 の Human Principles である。DS-001 は情報階層の外側、最上流に置かれる（OP-001 §13.0）。

THE THIRD PLACEは、人生を豊かに過ごすための「第三の場所」を設計・構築・運用するライフワークである。OP-001 · Preamble

人間・空間・道具・文化が、それぞれの役割を保ったまま、一つの世界として成立すること。OP-001 §2 · Core Philosophy

Human PrinciplesOP-001 §3

3.1Rational Satisfaction

私は、正しい答えを求めない。私は、自分自身が理性的に納得できる答えを求める。

3.2Independent Judgment

私は、判断を他人へ委ねない。最後に判断するのは、常に自分自身である。

3.3Accumulation

価値観は、書き換えない。否定しない。消さない。新しい価値観は、世界を広げる。

3.4Ordered Integration

異なる文化・思想・素材・機能・時代が、それぞれの役割を失うことなく、一つの秩序として成立している状態。

3.5Clear Purpose

ロマンとは、存在理由が極端に明確であることである。

3.6Completion

完成とは、モノが揃うことではない。完成とは、思考のノイズが消えることである。

縦書きの列は右から読む。Human Principles は THE THIRD PLACE 全体の Single Source of Truth とされる（OP-001 §4）。

                    Decision AuthorityOP-001 §19

                    最終意思決定者は、プロジェクトオーナーである。AIは、設計者ではない。

                    AI は調査、分析、制作、文書整理、事実確認、言語化、体系化を担当する。最終判断は必ず Human Principles に基づき、プロジェクトオーナー自身が行う。

                    AI Operating PrinciplesOP-001 §20

                    • 推測を事実として扱わない。

                    • GitHub Repository を正式な Single Source of Truth として扱う。
                    • GitHub 最新版を最優先で参照する。
                    • 責務が重複する文書を作らない。
                    • 既存思想を独断で変更しない。
                    • Popularity を判断基準にしない。
                    • Human Principles に反する提案を行わない。
                    • Design Bible を Constitution より優先しない。
