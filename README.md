🌄 概要（Overview）
THE THIRD PLACE は、可動式のアウトドア・リビングルーム（Movable Outdoor Living Room）の設計を目的とした長期デザインプロジェクトです。
単なるキャンプの記録ではなく、思想、建築・配置構造、道具、運用ワークフロー、ドキュメンテーション、そして長期的ナレッジ管理を統合した一貫性のあるデザインシステムを構築します。
本リポジトリにすべての公式文書を保持し、プロジェクトにおける唯一の真実のソース（Single Source of Truth / SSOT）として運用します。

🗃 マスターデータベース（Master Database）
TP-004 Equipment Registry Object Reference は、Human Principlesおよび美学的整合性によって統合管理される、キャンプギアのマスターデータベースです。
美学・空間領域における道具の参照、新規追加、更新、ライフサイクル管理のすべてはTP-004に帰属します。
なお、キッチン・調理用道具群に関しては機能主義的な選択基準に基づき、TP-011 Galley Fare にて個別に管理されます。
重複した道具データを保持することを避けるため、他のすべてのドキュメントはTP-004またはTP-011を参照します。

## 🌄 Overview
THE THIRD PLACE is a long-term design project dedicated to designing a movable outdoor living room.
Rather than documenting camping itself, the project establishes a unified design system integrating philosophy, architecture, equipment, workflow, documentation, and long-term knowledge management.
All official documents are maintained within this repository, which serves as the project’s Single Source of Truth (SSOT).

## 🗃 Master Database
**TP-004 Equipment Registry Object Reference** is the project’s master equipment database for camp equipment governed by Human Principles aesthetic alignment.
All aesthetic-domain equipment references, additions, updates, and lifecycle management originate from TP-004.
Kitchen cooking equipment is governed separately, under a function-first selection standard, by **TP-011 Galley Fare**.
Other documents reference TP-004 or TP-011 rather than maintaining duplicate equipment data.
