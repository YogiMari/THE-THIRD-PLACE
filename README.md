## Editing Rules (for Claude Code / contributors)

1. **SSOT を厳守する。** 情報の重複管理は禁止（PX-001 参照）。
2. Equipment 情報は `TP/TP-004_Equipment_Registry_Object_Reference.md` のみで管理する。
3. 新規文書追加前に、既存文書で対応できないか確認する（PX-001 §18.1）。
4. 文書を更新した場合は、当該ファイル内の Version / Revision History を更新する。
5. 推測で内容を埋めない。不明点は TBD のまま残し、一次情報確認後に反映する。
6. 本 README のテーブルは、ファイル追加・改名の都度更新する。
