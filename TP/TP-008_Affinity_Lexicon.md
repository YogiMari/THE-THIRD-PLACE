TP-008 Affinity Lexicon
# TP-008 Affinity Lexicon
## Ver.1.1

---

# 1. Purpose

## Position

Affinity Lexicon は、THE THIRD PLACE を構成する「好き」を語彙として定義する辞書である。

本書はブランドや製品を管理する文書ではない。

Design Bible に記された思想を、判断に使用する共通言語として整理・体系化することを目的とする。

---

## Role

Affinity Lexicon が扱うのは、

- 概念
- 美意識
- 感覚
- 空間性
- 建築性
- 素材性
- 工業性
- 文化性

である。

ブランドは語彙を体現する一例として扱うに留める。

---

## Principles

- 概念を優先する
- ブランドを目的化しない
- 人気・価格・希少性を評価しない
- Design Bibleとの親和性を基準とする
- 長期的に参照できる辞典として運用する

---

# 2. Structure

Affinity Lexicon は以下のカテゴリーで構成される。

1. Spatial Vocabulary
2. Architectural Vocabulary
3. Material Vocabulary

# 3. Vocabulary Entry Format

すべての語彙は共通フォーマットで管理する。

| Field | Description |
|--------|-------------|

| Affinity | Core / High / Medium / Low |

# 20. Affinity Classification

Affinity Lexiconに登録される語彙は、親和性によって分類する。

| Level | Meaning |
|--------|---------|
| Core | THE THIRD PLACEを象徴する最重要語彙 |
| High | 強く価値観を構成する語彙 |
| Medium | 空間品質を高める語彙 |
| Supporting | 他語彙を補完する語彙 |

# 21. Cross Reference

一つの語彙は複数カテゴリーと関連付けて管理する。

| Term | Related Categories |
|------|--------------------|

| Brass | Material / Light / Industrial |
| Hospitality | Spatial / Furniture / Coffee |
| Warm Light | Light / Emotional |
| Gravel | Landscape / Spatial |
| Timeless | Architecture / Cultural |
| Craftsmanship | Material / Cultural / Furniture |

# 22. Usage Policy

Affinity Lexiconは評価辞典ではない。

Equipment Registryで新しい道具を検討する際、

Design Bibleで思想を確認する際、

Habitat Architectureで空間を設計する際、

共通言語として参照される。

語彙はブランドより長く残る。

ブランドは変化しても、

Affinity Lexiconに定義された価値観は、

THE THIRD PLACEの設計思想を支える基盤として維持される。

# Revision Note (Ver.1.1)

Ver.1.1にて、全語彙エントリを第3章で定義したVocabulary Entry Format（Term / Category / Definition / Affinity / Related Terms / Opposite Concepts / Notes）へ正式に展開した。

Affinityは、他文書での言及頻度・中心性を基準とした初期評価であり、Related TermsはVer.1.0時点の掲載順に基づく近接語である。Opposite Conceptsは明確な対概念が存在する語のみ記入し、該当なしは「—」とした。

これらの評価は今後、実際の判断・使用実績に応じて見直される。
